# Neovim キーバインド一覧

**リーダーキー**: `<Space>`

## カスタムキーマップ (keymaps.lua)

### インサートモード
| キー | アクション | 説明 |
|------|-----------|------|
| `jj` | `<ESC>` | インサートモードを終了 |

### ノーマルモード

#### ナビゲーション
| キー | アクション | 説明 |
|------|-----------|------|
| `gt` | `:bnext` | 次のバッファ |
| `gT` | `:bprevious` | 前のバッファ |
| `<leader>h` | `^` | 行の先頭に移動 |
| `<leader>l` | `$` | 行の末尾に移動 |

#### ウィンドウ管理
| キー | アクション | 説明 |
|------|-----------|------|
| `<leader>sv` | `<C-w>v` | ウィンドウを縦分割 |
| `<leader>sh` | `<C-w>s` | ウィンドウを横分割 |

## LazyVim デフォルトキーマップ

### 移動・ナビゲーション
| キー | アクション | 説明 |
|------|-----------|------|
| `<Ctrl-h/j/k/l>` | ウィンドウナビゲーション | ウィンドウ間を移動 |
| `<Shift-h/l>` または `[b/]b` | バッファナビゲーション | バッファ間を移動 |
| `<Alt-j/k>` | 行の移動 | 行を上下に移動 |
| `j/k` または 矢印キー | カーソル移動 | 折り返しを考慮した上下移動 |

### 編集
| キー | アクション | 説明 |
|------|-----------|------|
| `<Ctrl-s>` | 保存 | 現在のファイルを保存 |
| `<` と `>` | インデント | ビジュアルモードでインデント |
| `gco/gcO` | コメント | 現在行の上下にコメント追加 |

### ウィンドウ管理
| キー | アクション | 説明 |
|------|-----------|------|
| `<Leader>-` | 下に分割 | ウィンドウを下に分割 |
| `<Leader>\|` | 右に分割 | ウィンドウを右に分割 |
| `<Leader>wd` | ウィンドウ削除 | 現在のウィンドウを削除 |

### 診断・検索
| キー | アクション | 説明 |
|------|-----------|------|
| `]d/[d` | 診断 | 次/前の診断 |
| `]e/[e` | エラー | 次/前のエラー |
| `]w/[w` | 警告 | 次/前の警告 |
| `n/N` | 検索 | 改良された検索ナビゲーション |

### 切り替え
| キー | アクション | 説明 |
|------|-----------|------|
| `<Leader>uf` | フォーマット切り替え | 自動フォーマットの切り替え |
| `<Leader>us` | スペルチェック切り替え | スペルチェックの切り替え |
| `<Leader>uw` | ワードラップ切り替え | 行の折り返しの切り替え |
| `<Leader>ul` | 行番号切り替え | 行番号表示の切り替え |

### ターミナル
| キー | アクション | 説明 |
|------|-----------|------|
| `<Leader>ft` | フローティングターミナル | フローティングターミナルを開く |
| `<Leader>fT` | タブターミナル | 新しいタブでターミナルを開く |
| `<Esc><Esc>` | ターミナル非表示 | ターミナルを隠す（ターミナルモード内） |

### Git
| キー | アクション | 説明 |
|------|-----------|------|
| `<Leader>gg` | LazyGit | LazyGitインターフェースを開く |
| `<Leader>gL` | Git ログ | Gitログを表示 |
| `<Leader>gb` | Git blame | 現在行のGit blame |

### ファイル操作
| キー | アクション | 説明 |
|------|-----------|------|
| `<Leader>fn` | 新しいファイル | 新しいファイルを作成 |

### プラグイン管理・ヘルプ
| キー | アクション | 説明 |
|------|-----------|------|
| `<Leader>l` | Lazy | Lazyプラグインマネージャーを開く |
| `<Leader>K` | ドキュメント | キーワードのドキュメントを表示 |

## プラグイン固有のキーマップ

### Claude Code
| キー | モード | アクション | 説明 |
|------|-------|-----------|------|
| `<leader>ac` | ノーマル | `:ClaudeCode` | Claudeターミナルの切り替え |
| `<leader>as` | ビジュアル | `:ClaudeCodeSend` | 選択範囲をClaudeに送信 |

### LazyGit
| キー | アクション | 説明 |
|------|-----------|------|
| `<leader>gg` | `:LazyGit` | LazyGitインターフェースを開く |

## バッファ管理
| キー | アクション | 説明 |
|------|-----------|------|
| `<leader>bd` | バッファ削除 | 現在のバッファを閉じる |
| `<leader>bD` | 強制バッファ削除 | 現在のバッファを強制的に閉じる |

## タブ管理
| コマンド | 説明 |
|----------|------|
| `:tabnew` | 新しいタブを作成 |
| `:tabclose` または `:tabc` | 現在のタブを閉じる |
| `:tabonly` または `:tabo` | 他の全てのタブを閉じる |
| `gt` / `gT` | タブ間を移動 |

## 一般的なVimコマンド
| コマンド | 説明 |
|----------|------|
| `:w` | ファイルを保存 |
| `:q` | 終了 |
| `:wq` | 保存して終了 |
| `:q!` | 保存せずに強制終了 |
| `:terminal` または `:term` | 現在のウィンドウでターミナルを開く |

---

*注意: この設定では `<leader>` はスペースキーにマップされています。*
